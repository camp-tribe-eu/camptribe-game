# Проба графіки: Kenney проти LPC (GAME-68, OD-007)

Одна й та сама сцена кемпінгу, зібрана з двох основ: трава, стежка, ставок, дерева, два намети,
вогнище, авто й троє з родини George (OD-011). Ціна проби — 0 €.

| файл | що це |
|---|---|
| `A-vs-B.png` | обидві сцени одна над одною, в однаковому розмірі на екрані |
| `scene-A-kenney.png` | Kenney Roguelike/RPG + Characters + Modern City, 16 px, 320×192 |
| `scene-B-lpc.png` | LPC, 32 px, 640×384 |
| `B-lpc-family-4dirs.png` | George, Victoria, Matthew з шарів генератора LPC: 4 напрямки |
| `scene_*.py`, `compose_chars.py` | скрипти складання: проба відтворюється з `research/packs/` |
| `CREDITS-lpc-characters.csv` | титри 17 шарів персонажів, вибрані з `CREDITS.csv` першоджерела |

Сцену зібрав скрипт, а не художник: розстановка й тайли — найпростіші. Порівнювати треба
**стиль і можливості**, а не композицію.

## Рекомендація чату Гри

**B · LPC** — бо лише він дає те, що власник назвав еталоном (OD-006), і анімованого персонажа
з редактором (бажання власника «персонажа створює гравець»).

Ціна LPC:

* титри й облік ліцензій по файлах (автоматизується, GAME-21);
* намет — домалювати або згенерувати (FAL, бюджет OD-010) і довести до палітри LPC;
* кемпер — так само;
* авто — перемасштабувати.

Kenney лишається для сірого прототипу S01–S02: CC0 дає нуль ризику, поки йде робота над ядром.

🔴 **Вибір — за власником (смак).** Ця проба лише показує обидва варіанти.
