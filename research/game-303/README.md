# GAME-303 · проба подачі вступу: комікс-панелі (А) і кінокадри (Б)

Проба, не конверсія. Одна сцена в двох виглядах — «родина кличе одне одного з різних кімнат» (Метью → Джордж → Вікторія, «Спати»),
ніч (сплять → їм сниться дорога) і ранок («Субота, 08:00», будильник, метушня). Решта вступу (пошук зарядки, лист, вибір героя, Атлас, мета)
не чіпається. **Усе, що йде за замовчуванням, — той самий вступ, що й був** (див. «Як вмикати»).

## Як вмикати

Лише збірка e2e (так само, як інші перемикачі `src/view/test-switches.ts`; у звичайній збірці параметр ігнорується):

* А, комікс: `/?intro=1&introStyle=comic`
* Б, кінокадри: `/?intro=1&introStyle=cinema`
* без `introStyle` (або `classic`) — нинішній вступ. Локально: `npx vite --mode e2e`, потім ці адреси (`&soloHero=1` — якщо потрібен велосипедний вибір).

## Знімки

Ті самі моменти в обох варіантах і обох орієнтаціях (`variant-a-…` — комікс, `variant-b-…` — кінокадри; `portrait` = 390×844, `landscape` = 932×430):

| NN | момент |
|----|--------|
| 01 | Метью покликав, Джордж відповів (комікс: 2 панелі з 3, третя ще порожня; кіно: кадр Джорджа) |
| 02 | Вікторія відповіла (комікс: усі 3 панелі, кожна репліка у своїй; кіно: кадр Вікторії) |
| 03 | Ніч: родина спить (комікс: 3 панелі; кіно: кадр Метью) |
| 04 | Сон про дорогу: авто, намет, багаття, родина (комікс: одна велика панель; кіно: кадр на весь екран) |
| 05 | Ранок, остання репліка метушні (комікс: 3 панелі з усіма репліками; кіно: кадр Джорджа) |

## Що зроблено

* `src/content/intro-scene.ts` — чиста модель: для кроку розкадровки → «вигляди» (які панелі, скільки показано, хто говорить). Прив'язка за **вмістом кроку** (вид + ключ тексту), а не за індексом, щоб вставки в `INTRO_STEPS` іншими агентами нічого не ламали (невідомий крок малюється як раніше). Сторож — `intro-scene.test.ts`.
* `src/view/intro-shot.ts` — художник кадру. Кімната з людиною зі **справжніх тайлів LPC** (ті самі `home_*.png` і листи персонажів, що в `intro-room.ts`, і спрайти авто/намету/багаття з гри). Нових файлів-картинок немає, ШІ нічого не малював. Малює один раз, збільшення цілим числом; жодних таймерів і rAF (рух — CSS).
* `src/ui/IntroScene.tsx` — обидва вигляди; `Intro.tsx` лише передає їм крок (дотики, «Пропустити вступ», біти квестів, звук — ті самі). Стилі — блок «GAME-303» в `index.html`.
* Звук — нічого нового (дзвіночок будильника й музика вступу — з `Intro.tsx`, як і були). Тексти uk + en (новий лише `intro.dream`).

## Що коштує дотягнути до решти вступу

Спільне для обох: моделі потрібні рядки в `VIEWS` для решти кроків, а для кадрів — нові «кімнати» у `intro-shot.ts`.

| | А: комікс-панелі | Б: кінокадри |
|---|---|---|
| Файли | `intro-scene.ts` (рядки на кожен крок), `intro-shot.ts` (кімнати/пози), CSS | те саме; панелі не потрібні |
| Арт | кожна нова панель — кімната + поза з наявних тайлів. Для «листа» і «Атласу» — панель з тими самими DOM-картками, що вже є | кожен кадр — ціла кімната; крупніший план → помітніше, чого не вистачає в LPC (обличчя сплячих, сидячі пози, кемпер/караван) |
| Нове | сторінки по 2–3 панелі: ≈ 6–8 сторінок на весь вступ | ≈ 14 кадрів; перехід «з темряви» вже є, перехресний (cross-fade) — ще ні |
| Ризик | довга репліка в вузькій панелі (портрет 390 px: ≈ 26 літер у рядку шрифтом гри) — потрібен ліміт довжини в контенті | довгі репліки не заважають (рамка розмови гри), але кожен кадр — окремий малюнок |
| Орієнтації | портрет — панелі стопкою, ландшафт — рядом; обидві перевірено e2e | портрет — кадр + рамка розмови знизу, ландшафт — те саме; обидві перевірено e2e |
| Оцінка | ≈ 1–1,5 дня на весь вступ | ≈ 2–2,5 дня (більше унікальних кадрів і монтажу) |

## Мій погляд на знімки (як гравець)

* Люди стоять на підлозі (тінь під ногами, ноги нижче лінії підлоги), нічого не висить у повітрі; меблі зі справжніх тайлів, світло/присмерк як у кімнаті вступу — це та сама гра, а не друга.
* А: у ландшафті три панелі в ряд читаються як сторінка коміксу, у портреті — стопка; кожна репліка — в панелі свого героя. Бульбашка трохи затуляє верх стіни (спинку ліжка, картину) — це ціна коміксу, герой лишається вільним. Довгу репліку Вікторії в портреті (≈ 75 літер) видно цілком у 3 рядки.
* Б: кадр великий і «дорогий» — сон і ранок виглядають найкраще, але одна людина в кадрі мало розповідає про те, що «вони в різних кімнатах». Переходи й наїзд — лише CSS (на знімках вимкнені, `animations: disabled`).
* Ціна лишається ручною там, де LPC не має арту: **обличчя сплячих** (показано потилицю на подушці — сплячий Джордж на дивані виглядає гірше за інших), **сидячі пози**, **кемпер** (у сні — звичайне авто), **вітальня з диваном** лише одна.

## Рекомендація

Для самих розмов брати **А (комікс)**: він прямо лікує «перекрикуються по квартирі» — кожен голос у своїй кімнаті, а сторінка накопичується, тож видно всю родину одразу і дешевше за кінокадри в усіх розкладках. Для ніч → сон → ранок взяти з **Б** лише повнокадрові шоти (сон про дорогу, будильник): обидва варіанти вже ділять один художник кадру (`intro-shot.ts`), тож гібрид — це лише список вигляд-на-крок у `intro-scene.ts`.
