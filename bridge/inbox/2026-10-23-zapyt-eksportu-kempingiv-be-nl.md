### Схема (v1)

```json
{
  "format": "camptribe-campsites",
  "version": 1,
  "exportedAt": "РРРР-ММ-ДД",
  "source": "звідки зріз, словами",
  "licence": { "name": "ODbL 1.0", "url": "https://…", "attribution": "© OpenStreetMap contributors" },
  "campsites": [
    {
      "id": "cs.назва-латиницею",
      "name": "Camping …",
      "country": "BE",
      "lat": 50.3,
      "lon": 5.8,
      "kind": "campsite",
      "tents": true,
      "campers": true,
      "pets": null,
      "season": { "from": "04-01", "to": "10-31" },
      "checkedAt": "РРРР-ММ-ДД"
    }
  ]
}
```

Правила, які перевіряє сторож:
* `country` — лише `BE` або `NL`; координати мають лежати в межах країни (ловить переставлені lat/lon);
* `kind` — `campsite` | `camper-park` | `nature-camp`;
* `tents` / `campers` / `pets` — `true` | `false` | `null`;
* `season` — `null` (цілий рік) або `{ from, to }` у форматі ММ-ДД;
* `id` — `cs.` + `[a-z0-9-]`, без повторів;
* дати — справжні РРРР-ММ-ДД (31 лютого — помилка), не в майбутньому; порожній список — помилка;
* файл збережено рівно як `JSON.stringify(дані, null, 1) + "\n"` — так дубль ключа не пронесе в публічний
  репозиторій зайвого тексту, а diff лишається читабельним;
* у `name`, `source`, `licence.attribution` — жодних пошт, телефонів чи посилань (сторож їх шукає).

🔴 **Жодних персональних даних:** власники, телефони, пошта, відгуки, рейтинги, ціни конкретного бізнесу. Будь-яке поле
поза схемою — червоне, це навмисно. NPC гри до реальних бізнесів не прив'язуються (GAME-55).
