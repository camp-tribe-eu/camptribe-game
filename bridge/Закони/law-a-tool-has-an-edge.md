# Інструмент має межу, і мовчання на ній — не факт

Інструмент мовчить на своїй межі, і це мовчання читається як факт.
Порожній вивід — це збій, поки не доведено протилежне.

**Що робити завжди:**
1. Порожній результат із кодом 0 розслідувати, а не приймати.
2. Короткий SHA, урізаний `head`, назва джоби замість workflow — кожне
   з них віддає неправду тихо.
3. Ніколи `export $(...)`: порожня підстановка друкує весь environment.
4. Діагностика сама друкує секрет — питати про файл збоку, не через
   stderr того, хто його читає.
