# Запити на генерацію

Файл `назва.json`, потім **Actions → art → Run workflow**, у полі `request` — ім'я файлу.

```json
{
  "endpoint": "fal-ai/flux/schnell",
  "tile": true,
  "tile_size": 32,
  "colors": 16,
  "payload": {
    "prompt": "…",
    "image_size": "square_hd",
    "num_images": 1,
    "num_inference_steps": 4
  }
}
```

`"tile": true` вмикає конвеєр доведення до стикування. Для портретів, іконок і концептів
став `false` — їм стикування не потрібне.

🔴 Чекай від конвеєра геометрії, не краси. Він зводить шов до ~0.5, але зміст лишається таким,
яким його намалювала модель. Для тайлів ландшафту це поки не дає рівня готової гри —
заміри в `brain/Передача/03-zamir-grafiky.md`.
