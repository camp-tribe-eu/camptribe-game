Цей файл — твій індекс пам'яті. Поки він майже порожній: проєкт починається 22.10.2026, і
власних помилок у тебе ще немає.

🔴 **Але вісім законів ти успадковуєш готовими.** Вони виведені чатом Сайту з ~160 власних
помилок на цьому ж бізнесі й лежать у `../\_spilne/Закони/`. Не переплачуй за них удруге.

## Успадковане — читати, не переписувати
- `../_spilne/Закони/` — вісім законів, повні тексти з випадками
- `../_spilne/decisions/` — рішення власника, що діють і для гри
- `../_spilne/ZONES.md` — межа між зоною гри й зоною сайту
- `../_spilne/STATE.md` — заміряний стан обох напрямків

## Своє — писати сюди
Коли зробиш власну помилку і зрозумієш причину — заведи файл поруч і додай рядок сюди.
Формат той самий, що в чату Сайту: один файл = один факт, frontmatter із `name`, `description`,
`metadata.type` (`user` / `feedback` / `project` / `reference`), у тілі **Чому** і **Як
застосовувати**.

Правило відбору: записувати те, що **не виводиться з коду й історії git**. Структуру проєкту,
минулі виправлення й те, що вже є в `CLAUDE.md`, сюди не дублювати.
