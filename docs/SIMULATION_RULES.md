# SIMULATION_RULES · як живе світ гри

Єдині правила для всіх систем ядра. Числа, позначені **(тимч.)**, — найпростіша узгоджена
величина за CR-062. Їх можна міняти без нового рішення, але в одному PR із тестом. Формат:
`id` · правило · джерело · статус.
