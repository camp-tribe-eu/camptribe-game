# Сторож палітри (GAME-22)

Закон власника: гармонію вбиває змішування наборів. Новий спрайт доводиться до палітри
основного набору — або не додається. Основа — **LPC** (OD-013); набір задається аргументами,
тож Kenney-палітра для сірого прототипу збирається тим самим скриптом.

Python 3 + Pillow. Запуск із кореня репозиторію.

```
python3 scripts/palette/extract.py                  # палітра LPC -> art/palette/lpc.json
python3 scripts/palette/extract.py --check          # червоне, якщо lpc.json застарів
python3 scripts/palette/check.py --allow-missing    # кожен PNG у assets/ — лише кольори палітри
python3 scripts/palette/quantize.py IN.png OUT.png  # довести спрайт до палітри
python3 scripts/palette/self_test.py                # самотест + 10 мутацій
```

## Палітра

`art/palette/lpc.json`: RGB кожного пікселя з alpha > 0 з
`research/packs/pack-lpc-atlas/terrain_atlas.png` (451 колір) і `base_out_atlas.png` (130).
Разом **498 кольорів**, із sha256 кожного джерела. Шарів персонажів LPC у репозиторії немає:
коли вони з'являться, їх додають аргументами до `extract.py`.

## Коди `check.py`

| код | статус | коли |
|---|---|---|
| 0 | `PASS` | кожен видимий піксель кожного PNG — у палітрі |
| 0 | `NOT RUN` | теки немає або в ній нема PNG, і дано `--allow-missing`. Це не `PASS` |
| 1 | `FAIL` | чужі кольори; або тека порожня без `--allow-missing`; або PNG не читається |
| 2 | `ERROR` | палітра не читається, від'ємний допуск |

На кожен файл: кількість чужих кольорів, пікселів і до 10 прикладів `#rrggbb ×N`.

## Правила

* Піксель з alpha = 0 не перевіряється. Будь-який alpha > 0 перевіряється за RGB.
* `--tolerance` — евклідова відстань у RGB. Типово **0 = точний збіг**.
* `quantize.py`: alpha < 128 → прозорий, інакше 255; колір → найближчий у палітрі. Це механічний
  перший прохід: він робить сторожа зеленим, але не гарантує, що спрайт виглядає добре. Контур,
  світло й масштаб перевіряє людина.

## Перевірка на справжніх картинках (22.10.2026, допуск 0)

| файл | результат |
|---|---|
| `research/art-spike/scene-B-lpc.png` (сцена LPC) | FAIL: 296 чужих кольорів, 18 408 із 245 760 px (7,5 %) — змішування напівпрозорих тайлів, тоновані персонажі, авто, вогнище |
| `research/art-spike/scene-A-kenney.png` | FAIL: 60 із 60 кольорів чужі, 61 440 із 61 440 px |
| те саме після `quantize.py` | PASS |
| `pack-lpc-tent/Tent_1.png` (інший автор) | FAIL: 1 чужий колір `#986a20` ×28 |
| те саме після `quantize.py` | PASS |

Повна сцена не є спрайтом: сторож перевіряє окремі PNG, а не кадр після змішування.

## Межі (закон 5)

* **Допуск не вмикати.** При 32 сцена Kenney проходить майже вся (лишається 1 632 px із
  61 440), і сторож стає декоративним: ціна хибно-зеленого — змішані набори в грі. При 0 ціна
  хибно-червоного — один прогін `quantize.py` і погляд на результат, хвилини.
* Палітра з 498 кольорів не ловить чужий **стиль** у кольорах LPC: інший контур, кут, масштаб.
* Напівпрозорі пікселі атласу (тіні, alpha 153–214) дають нові кольори лише після змішування,
  тому в спрайтах вони дозволені, а в кадрі — ні.
* Персонажі LPC, перефарбовані тонуванням (`compose_chars.py`), вийдуть за палітру: їх треба
  або квантувати, або додати шари генератора в джерела палітри окремим рішенням.
