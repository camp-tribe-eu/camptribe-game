# CONTENT_REGISTRY · реєстр контенту

Хто й що існує у світі гри, з постійними id. Реєстр — план. Формат id — як у валідаторі: `префікс.назва` з `[a-z0-9-]` (дефіс, не підкреслення). Правда — `content/`, коли файли
з'являться: тоді валідатор звіряє унікальність id. Кожен NPC унікальний (CR-016): одна людина
не з'являється в іншій країні під новим ім'ям.

Усі персонажі вигадані (`DISCLAIMER.md`). Збіг з реальними людьми випадковий.
