# Інфраструктура: доступи, секрети, Jira, Git

🔴 **Головне про середовище.** Чат Гри працює у **вебі** (`claude.ai/code`), а не на Mac
власника. Причина: власник не може тримати дві десктопні сесії різних акаунтів одночасно —
перемикання вбиває поточну.

Наслідок, із якого випливає вся конструкція: **ноутбука власника для тебе не існує.** Немає
`~/.claude/secrets.env`, немає локальної БД, немає його файлів. Усе, що тобі потрібно, має
лежати в цьому репозиторії або в секретах GitHub.

Добра новина: браузерній грі ноутбук і не потрібен.

## Git

| що | значення |
|---|---|
| репозиторій гри | `camp-tribe-eu/camptribe-game` — **публічний** |
| місток із чатом Сайту | `camp-tribe-eu/camptribe-game`, тека `bridge/` — приватний, клонується окремо |
| репозиторій сайту | `camp-tribe-eu/camp` — **публічний, тобі тільки читати** |
| гілка | `main`, зміни через PR |

🔴 **Чому публічний.** Персонажі й домогосподарства в проєкті **вигадані** — твердження
власника, автора документа (`DISCLAIMER.md`). Приклад домогосподарства в GDD це
ілюстративний профіль для перевірки механік, а не реальна родина. Секретів у репозиторії
немає — вони живуть у GitHub Actions secrets, і це перевіряє `secrets-scan.yml` на кожен PR.

Публічний дає те, чого приватний на Free не дає: **безкоштовний захист гілки** і
**безлімітні Actions**.

🔴 **Наслідок, який треба тримати в голові:** усе, що ти комітиш, читає будь-хто. Перед
кожним комітом питай, чи витримає цей рядок чужі очі.

**Потік змін:** гілка → PR → CI зелений → **рецензент** → злиття → картка в Jira.
Чат, який написав код, не є незалежною перевіркою власного коду.

## Секрети — і чому їх тут немає

У репозиторії **жодного секрету**. Ні ключа, ні токена, ні пароля, ні хеша, ні адреси
прод-машини. `.gitignore` це закріплює, а `secrets-scan.yml` перевіряє на кожен PR.

| секрет | де лежить | як ним користуватись |
|---|---|---|
| `FAL_KEY` | **Settings → Secrets and variables → Actions** | тільки через `art.yml`; у чат не копіювати |

🔴 **Ключ FAL не має потрапляти в чат.** Генерація арту працює так: ти кладеш файл-запит у
`art/requests/`, запускаєш workflow `art.yml`, він викликає fal із секрету й комітить результат
у `art/out/`. Ключ не бачить ні чат, ні репозиторій.

Якщо знадобиться новий секрет — **не проси надіслати його в чат.** Проси власника додати в
Actions secrets і скажи точну назву змінної.

## API: що доступно через один ключ FAL

Заміряно 22.10.2026 живими викликами.

**Зображення:** `fal-ai/flux/schnell` — **$0.003 за 1 Мп**, найдешевший робочий варіант.
`fal-ai/recraft/v3/text-to-image` зі `style: "digital_illustration/pixel_art"` — справжній
піксель-арт, дорожчий.

**Текст — через `fal-ai/any-llm`, 30 моделей одним ключем.** Перевірено на `openai/gpt-4o`,
`openai/gpt-4o-mini`, `meta-llama/llama-3.2-3b-instruct` — усі відповіли 200. Доступні також
`openai/gpt-5-chat`, `gpt-5-mini`, `gpt-5-nano`, `o3`, `gpt-4.1`, `anthropic/claude-sonnet-4.5`,
`claude-haiku-5.5`, `google/gemini-2.5-pro`, `gemini-2.5-flash`, `gemini-2.5-flash-lite`,
`meta-llama/llama-4-maverick`, `llama-4-scout`, `deepseek-v3.1-terminus`, `moonshotai/kimi-k2.5`.

Це закриває генерацію діалогів: окремий акаунт ChatGPT не потрібен, усе йде через один ключ і
один баланс.

🔴 **Але гра не має залежати від генеративного ШІ під час проходження.** Моделі допомагають
**створювати** контент; сам контент лягає у файли й перевіряється валідатором. Гравець має
грати офлайн і передбачувано.

**Бюджет:** на 22.10.2026 баланс $23.41. Чат Сайту витратив на заміри ≈ $0.04.
Називай вартість у звіті, коли вона перевищує цент.

## Jira

| що | значення |
|---|---|
| cloudId | `835bc68c-b910-4902-bfeb-cc081f8f93df` |
| проєкт гри | `GAME` — **створює власник**, через MCP проєкти не створюються |
| проєкт сайту | `CAMP` — **не чіпати** |

Ключ картки в коміті — це договір: предмет картки має збігатися з тим, що реально змінено.
Перед тим як ставити `GAME-NNN` у коміт, звір із `git show --stat`.

🔴 **Перед створенням будь-якої картки — JQL за ПРЕДМЕТОМ** (`text ~ "…"`), а не за ключем.
Інакше заведеш дубль.

## Чого ти НЕ маєш і не проси

| ресурс | чому |
|---|---|
| прод-сервер Hetzner | зона чату Сайту. Гра на ньому не живе |
| БД сайту | пряма залежність заборонена: впаде одне — постраждає інше |
| DNS, домени, Cloudflare | зона чату Сайту |
| Directus CMS | зона чату Сайту |
| картки `CAMP-*` | чужа дошка |

Потрібні дані ЄС-27 (кемпінги, маршрути, тарифи) — **нотатка в `bridge/inbox/`** із рядком
`**Питання до:** чат Сайту`. Він підготує експорт зрізу у файл. Так дані приходять, а
залежності не виникає.

## Перші п'ять хвилин: перевір середовище сам

Не вір цьому документу — він написаний не з того середовища, де ти працюєш. Перевір:

1. `git log --oneline | head` — репозиторій склонований і історія на місці?
2. `ls brain/Передача/` — п'ять файлів передачі?
3. `curl -s -o /dev/null -w '%{http_code}' https://fal.run/` — мережа назовні працює?
4. `node --version && npm --version` — є чим збирати?
5. чи бачиш Jira через MCP — якщо ні, власник має підключити конектор Atlassian у цьому акаунті.

🔴 Що не працює — **запиши в `bridge/inbox/` з кодом помилки**, а не обходь мовчки.
Порожній вивід із кодом 0 — це збій, а не відповідь.
