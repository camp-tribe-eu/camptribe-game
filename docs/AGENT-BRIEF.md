# Спільний бриф для агента-виконавця картки

Кожне завдання агенту посилається на цей файл замість того, щоб повторювати правила. Прочитай його ПЕРЕД роботою разом
із `CLAUDE.md`. Тут — лише механіка; що робити — у самому завданні.

## 0. Обсяг і бюджет

* Картка = один PR на **≤ 1–2 години** роботи. Не влазить — зроби найцінніший шматок, решту опиши в звіті як «наступний PR».
* Бюджет викликів інструментів дано в завданні. На **половині бюджету** — `WIP`-коміт і пуш (контейнер може перезапуститись).
  Бюджет закінчується — спершу коміт+пуш, потім звіт. Ніколи не лишай роботу незакоміченою.

## 1. Старт

```bash
cd <worktree>            # дає завдання; node_modules уже посилання
git fetch origin main && git merge origin/main   # працюєш на свіжому main
```

## 2. Правила, що найчастіше порушувались (06.11)

1. **Закон 1:** кожен новий сторож показано червоним мутацією; у звіті — текст червоного повідомлення.
2. **Таймаути не піднімати, retry/skip/only не додавати, перевірки не послаблювати.** Тест повільний — розділи його
   (зразок: `tests/e2e/day1-fixture.ts`, GAME-255) або чекай на стан, не на час.
3. **Типи e2e — окремий конфіг:** `npx tsc --noEmit -p . && npx tsc --noEmit -p tsconfig.e2e.json`. Забули — CI червоний.
4. **Вступ у e2e — лише через `tests/e2e/intro-walk.ts`** (`walkIntro`, `skipIntroToMorning`), без власних циклів «Далі».
5. **Знімки для `research/` — не на критичному шляху тесту:** лише за змінною середовища (зразок `HOME_SHOTS=1`).
6. **Фікстура дня 1** (`tests/e2e/fixtures/day1-bike.json`): змінив стан кінця дня 1 — перезапиши `G255_WRITE=1` і скажи про це.
7. **Жодного `git stash pop`** (стек спільний з іншими сесіями) — тимчасовий `WIP`-коміт.
8. **Новий тип запису журналу** → значок у `src/ui/journal-model.ts` (сторож це ловить).
9. **Ворота якості картинки** (`docs/GAME-LOOP-V2.md` §8): видима зміна → знімки до/після 390×844 і 932×430 у PR.

## 3. Перевірка перед пушем (одна, повна — щоб CI пройшов з першого разу)

```bash
npx tsc --noEmit -p . && npx tsc --noEmit -p tsconfig.e2e.json && npx eslint src tests
npx vitest run <зачеплені теки>        # повний — якщо чіпав ядро/контент
CI=1 PW_CHROMIUM_PATH=/opt/pw-browsers/chromium-1243/chrome-linux64/chrome PW_PORT=<з завдання> timeout 900 \
  npx playwright test <зачеплені specs> --workers=2 --reporter=line --project e2e --project e2e-heavy
git checkout -- research/visual-audit; git clean -fq research/visual-audit test-results
```

`--workers=2` максимум — в контейнері паралельно працює ще один агент.

## 4. Коміт, пуш, PR

* Трейлери коміту:
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` і `Claude-Session: <посилання сесії з завдання>`.
* Пуш: `for d in 2 4 8 16; do git push -u origin <гілка> && break; sleep $d; done`
* PR — `mcp__github__create_pull_request` (owner `camp-tribe-eu`, repo `camptribe-game`), заголовок «GAME-NNN: …»,
  тіло українською: що й навіщо, докази (числа, RED-повідомлення), знімки, **NOT RUN** — чесно. Кінець тіла — два рядки
  з завдання («🤖 Generated with …» і посилання сесії).

## 5. Звіт (≤ 6 рядків)

PR, head SHA, що зелене (з числами), що NOT RUN, що лишилось. Без переказу процесу.
