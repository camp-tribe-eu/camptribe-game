# OPEN_QUESTIONS · відкриті питання, невідоме, залежності

Щоб важливе не загубилося серед сотень задач. Кожен запис має:

* питання;
* чому воно важливе;
* рекомендацію;
* критерій закриття;
* адресата;
* статус: `OPEN` / `INVESTIGATING` / `DECIDED` / `VERIFIED` / `BLOCKED`;
* дату.

🔴 `VERIFIED` ставиться лише з доказом: тест, джерело, заміряний результат. Переконлива
відповідь ШІ — не доказ (GDD OPEN_QUESTIONS, правила ведення).
