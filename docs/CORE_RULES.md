# CORE_RULES · незмінні правила гри

Джерело правди для кожного, хто пише код або контент CampLife. Якщо картка, промпт чи
пропозиція суперечить цьому файлу — не змінюй правило мовчки: назви конфлікт і запиши
рішення в `DECISION_LOG.md`.

Формат рядка: `id` · правило · джерело · статус. Джерела:

* `GDD §…` — розділ дизайн-документа власника (приватний, тут лише переказ);
* `OD-…` — рішення власника;
* `TD-…` — технічне рішення.

Статуси: `ACCEPTED` — діє; `PROPOSED` — чекає підтвердження.
Перевірка формату: `node scripts/check-rules.mjs`.
