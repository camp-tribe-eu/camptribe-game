# game-art-sources · графіка з першоджерел, з ліцензією

## 0. Спершу — як це виглядає в житті (OD-024, власник 31.10.2026)

🔴 Перед будь-якою новою сценою чи предметом (магазин, каса, кемпінг, лікарня, супермаркет…) — **≥ 10–12 справжніх фото**
і нотатка «що насправді є». Одне фото може бути хибним. Не вигадуй оточення: у магазині спорядження не буває
книжкових полиць.
1. Рядок у `research/fetch.txt`: `refs-<тема>\trefs:<запит>|<запит>|…` (англ. запити; Openverse — перше джерело,
   Commons — друге). Після пушу рядка запусти runner вручну (`gh workflow run research-fetch.yml --ref <гілка>` або Actions → research-fetch → Run workflow → вибери гілку); мініатюри з вільною ліцензією й `CREDITS.txt` комітяться в `research/refs/<тема>/`.
2. **Подивись очима** (контакт-аркуш через PIL) і відкинь нерелевантне — лічильник «≥ 10» сам нічого не доводить
   (перший прогін 31.10 приніс скани книжок і військові табори 1918).
3. Допиши `research/refs/NOTES.md`: що стоїть, де, хто де стоїть, чого там не буває. Малюй за нотаткою.

## 1. Мережа: що доступно звідки (заміряно 22.10.2026)

| джерело | із сесії | із runner GitHub |
|---|---|---|
| kenney.nl, opengameart.org, Steam, itch.io | 🔴 закрито | ✅ |
| raw.githubusercontent.com | ✅ | ✅ |
| api.github.com без токена | 🔴 403 | ✅ |
| артефакти Actions (blob storage) | 🔴 закрито | — |

Тому з OGA і Kenney матеріал забирає **runner** і **комітить у гілку**. Артефакти Actions
недоступні: не витрачай на них час.

## 2. Як забрати набір

1. Додай рядок у `research/fetch.txt`: `назва<TAB>джерело`.
   * `kenney:<slug>` — сторінка `kenney.nl/assets/<slug>`;
   * `oga:<slug>` — `opengameart.org/content/<slug>`;
   * `ogasearch:<слова>` — лише список сторінок, нічого не качає;
   * `steam:<appid>` — опис і скриншоти, **ніколи не комітяться**.
2. Назва `pack-*` — комітиться в `research/packs/<назва>/`; `list-*` — у `research/lists/`.
3. Запушивши гілку, запусти вручну `.github/workflows/research-fetch.yml` (workflow_dispatch, `--ref <гілка>`; пуш його більше НЕ запускає — GAME-223). Чекай коміт від `research-bot`:
   `until git fetch -q origin <гілка> && git log --format=%an HEAD..origin/<гілка> | grep -q research-bot; do sleep 10; done`
4. Набір без ліцензії, процитованої зі сторінки першоджерела, **не комітиться**. Замість нього
   в `research/debug/<назва>.txt` лягає фрагмент розмітки блоку ліцензії.

### Пастки, на які вже наступили

* OGA пише `href='…'` в **одинарних** лапках. Регулярка лише на `"` → «ліцензію не знайдено».
* `git add a b c`, де хоч одного шляху немає, **не додає нічого**. А `|| true` це ховає.
  Додавай лише наявні теки.
* `cmd | head` при `set -o pipefail` → код 141 (SIGPIPE). Рахуй через `wc -l`.
* Kenney: 1700 окремих тайлів — беремо лише зведені аркуші (`*sheet*`, `*tilemap*`).
* Zip із Mac несе `__MACOSX/` — видаляй.

## 3. Ліцензії — що можна

| ліцензія | можна | умова |
|---|---|---|
| CC0 | ✅ | нічого |
| OGA-BY 3.0 | ✅ | титри; дозволена й DRM-збірка |
| CC-BY 3.0/4.0 | ✅ | титри; DRM-збірка — під питанням |
| CC-BY-SA 3.0/4.0 | ✅ для вебу | титри; **змінену графіку** публікуємо під тією ж ліцензією |
| GPL 2/3 | лише якщо іншого варіанта нема | не обирай для графіки, коли є CC-BY-SA/OGA-BY |

Кілька ліцензій через `|` означає вибір: беремо найм'якшу для нашої мети.

LPC-персонажі: титри по шарах — у `CREDITS.csv` генератора
(`LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator`, тягнеться з raw). Скрипт
вибирає рядки для кожного використаного шару. Кількість рядків має дорівнювати кількості
шарів, інакше червоне.

Сторож (`scripts/assets/check-assets.mjs`) звіряє `licences_offered` кожного шару з випискою
першоджерела `research/art-spike/CREDITS-lpc-characters.csv` (`CREDITS_UPSTREAM_MISMATCH`).

Колонка **`modified`** у `CREDITS.csv`: `no` — файл байт у байт як у джерелі; інакше — опис
змін (≥ 8 символів), бо CC-BY-SA вимагає їх назвати. Змінений файл під CC-BY-SA лишається
CC-BY-SA (`CREDITS_SA_RELICENSED`).

`assets/CREDITS.csv` і `docs/LICENSE_REGISTER.md` зливаються union-ом (`.gitattributes`, GAME-223): рядки з різних
гілок не конфліктують, а рядок, змінений в обох, стає дублем — його ловлять `CREDITS_DUPLICATE` і
`REGISTER_DUPLICATE_ID`; лиши один.

**`public/`** не має рядків титрів, тож туди можна лише CC0 або OFL (текст ліцензії поруч у
`public/`). Усе, що вимагає атрибуції, — лише в `assets/` (`PUBLIC_NEEDS_CREDITS`). Кожен медіафайл
у `public/` має рядок у `docs/LICENSE_REGISTER.md` (`PUBLIC_NO_REGISTER_ROW`).

🔴 **Агрегатор не ліцензує.** Ліцензію цитуємо зі сторінки автора, а не з чужого репозиторію,
що «зібрав усе».

## 4. Гармонія (закон власника)

Новий об'єкт доводиться до палітри, масштабу й напрямку світла основного набору — або не
додається. Ознаки, що об'єкт чужий: інша товщина контуру, інший кут (плаский проти 3/4),
масштаб ≠ сітці (LPC 32 px, Kenney 16 px). На пробі LPC так виглядають намет `tent-3` і авто
Skorpio (на ~30 % завелике).

## 4а. Світ правдивий: перспектива, масштаб, розміщення (OD-026, власник 31.10.2026)

Ця вада — не однієї сцени: так було скрізь. Перед будь-яким предметом, будівлею чи сценою:

1. **Проєкція LPC 3/4, ортогональна.** Передня грань паралельна екрану; верх — смужка зверху; бокові грані не видно (або
   ледь). Ізометрія (ромб, діагональні низ і верх), перспектива з точками сходу, «вид збоку без верху» — чужі. Будівля
   стоїть кутами по сітці мапи.
2. **Масштаб ≈ 28 px/м** (дорослий ≈ 47 px). Довідник справжніх розмірів — `art/world-scale.json`; новий предмет
   спершу отримує там рядок зі справжніми метрами, потім малюнок. Порядок у житті = порядок на екрані.
3. **Світло зліва згори, контур і палітра основи** (§4).
4. **Лінійка перед PR:** аркуш, де кожен новий предмет стоїть поруч із героєм і з сусідами за розміром (авто, причіп,
   намет, двері), + знімок сцени в грі. Без цього PR із графікою не відкривається.
5. **Розміщення як у житті:** спершу план із фото (ділянки, дороги, зони), потім предмети — групами за функцією.
6. **ШІ-предмет:** у запиті — «LPC 3/4 top-down orthographic, front face parallel to the screen, no isometric, no
   perspective»; результат проходить сторож `scripts/art/check_world.py` і лінійку, інакше — у кошик.

## 5. Відомі прогалини

* **Кемпер / караван** — немає ні в Kenney, ні в LPC.
* **Намет у стилі LPC** — не знайдено.

Шлях для обох: FAL у межах OD-010 ($10). Далі ручне доведення до палітри основи, і лише після
цього — у `assets/` із рядком у `docs/LICENSE_REGISTER.md`. Ліцензію згенерованого записуємо
за умовами FAL на день генерації.

## 6. Проба сцени

збирається з `research/packs/`, тож пробу можна відтворити будь-коли.
